# Lembar Pengujian UAT (User Acceptance Testing Checklist)
## SIM Kos & Guesthouse — Tenant Identity UX & Unified Room Services

| ID Pengujian | Skenario Pengujian | Langkah Pengujian | Hasil yang Diharapkan | Status |
|:---:|---|---|---|:---:|
| **UAT-ID-01** | Tampilan Profil & Masking NIK Penyewa | Buka aplikasi mobile sebagai Penyewa -> Masuk tab *Profil*. | Ditampilkan kartu Identitas Kependudukan dengan NIK bermasking (`3507********0004`), kontak darurat, pekerjaan, dan tombol *Edit Data Identitas*. | **PASS** |
| **UAT-ID-02** | Bantuan Pemindaian KTP via OCR (Opsional) | Klik *Edit Data Identitas* -> Pilih *Pindai Foto KTP* -> Ambil gambar kartu KTP. | OCR memindai teks on-device dan memunculkan pop-up modal preview NIK & Nama. Data tidak otomatis menimpa sebelum pengguna menekan tombol *Terapkan*. | **PASS** |
| **UAT-ID-03** | Pengisian Manual Data Identitas | Buka form Edit Identitas -> Ketik NIK 16 digit, Nama, Kontak Darurat, Pekerjaan, Plat Motor -> Klik Simpan. | Tombol simpan nonaktif sesaat (anti-duplicate click). Data tersimpan sukses, pesan notifikasi muncul, dan NIK tersimpan aman di database dengan blind index hash. | **PASS** |
| **UAT-ID-04** | Validasi Anti-Duplikasi NIK Antar Penyewa | Coba masukkan NIK yang sudah pernah terdaftar pada penyewa lain dari akun berbeda. | Backend menolak dengan status HTTP 422 dan pesan ramah: *"NIK KTP ini sudah terdaftar pada akun penyewa lain di sistem."* Data tidak tertimpa. | **PASS** |
| **UAT-RS-01** | Akses Hub Layanan Kamar Terpadu | Klik ikon *Layanan* pada navigasi bawah atau pilih *Layanan Kamar Saya* dari profil penyewa. | Terbuka layar `RoomServicesHubScreen` yang menampilkan banner unit aktif penyewa, kartu pilihan *Pembersihan Kamar* & *Inspeksi Kamar*, serta live tab status permohonan terkini. | **PASS** |
| **UAT-RS-02** | Pengajuan Pembersihan Kamar oleh Penyewa | Dari hub layanan, klik *Ajukan Pembersihan* -> Pilih tanggal, sesi waktu (Pagi/Siang/Sore), catatan -> Kirim. | Tugas tercatat di backend berstatus `SCHEDULED`, otomatis terasosiasi dengan kamar aktif penyewa, dan muncul pada live list tugas. | **PASS** |
| **UAT-RS-03** | Penolakan Pengajuan untuk Kamar Bukan Milik Sendiri | Coba kirim request housekeeping/inspeksi dengan akun user yang tidak memiliki booking kamar aktif. | Sistem menolak dengan HTTP 422/403: *"Anda tidak memiliki hak akses hunian pada kamar ini."* | **PASS** |
| **UAT-RS-04** | Disposisi Staf oleh Pengelola (Web Dashboard) | Login Web Dashboard sebagai Manajer -> Buka detail tugas / inspeksi -> Klik *Tugaskan Staf* / *Disposisi Petugas*. | Modal Bootstrap terbuka, menampilkan staf properti terkait -> Simpan -> Status berubah menjadi `ASSIGNED`, staf menerima notifikasi in-app. | **PASS** |
| **UAT-RS-05** | Penjadwalan Ulang (Reschedule) oleh Pengelola | Buka detail tugas di Web Dashboard -> Klik tombol *Jadwalkan Ulang* -> Ubah tanggal dan sesi waktu -> Simpan. | Jadwal tugas diperbarui, riwayat reschedule tercatat dalam log audit, dan notifikasi dikirimkan ke pihak terkait. | **PASS** |
| **UAT-RS-06** | Pengerjaan Staf & Penyerahan Verifikasi | Staf login di mobile -> Buka tugas -> Klik *Mulai Pembersihan* -> Centang checklist tugas -> Klik *Serahkan untuk Verifikasi*. | Status beralih ke `PENDING_VERIFICATION`, timestamp selesai dicatat, dan penyewa menerima pemberitahuan untuk memeriksa unit kamar. | **PASS** |
| **UAT-RS-07** | Konfirmasi Selesai oleh Penyewa ("Sesuai") | Penyewa membuka detail tugas berstatus `pending_verification` -> Klik tombol hijau *Konfirmasi Selesai* -> Masukkan ulasan kepuasan. | Status tugas berubah menjadi `COMPLETED`, field `verified_by` mencatat ID penyewa, timestamp verifikasi terisi, dan staf menerima konfirmasi terima kasih. | **PASS** |
| **UAT-RS-08** | Permintaan Perbaikan oleh Penyewa ("Belum Sesuai") | Penyewa membuka tugas `pending_verification` -> Klik tombol *Minta Perbaikan* -> Pilih item checklist yang kurang bersih -> Tulis alasan -> Kirim. | Tugas mencatat log perbaikan beserta daftar item bermasalah, foto hasil pengerjaan awal staf tetap aman tersimpan, dan pengelola serta staf menerima peringatan perbaikan. | **PASS** |
